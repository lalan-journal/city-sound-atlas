## 中文

一份关于「城市」的中文播客听单。

不听攻略，听本地人怎么讲自己的城——历史、美食、地方志，按地方归档。
目前收录 **33 个城市 / 区域、241 期、约 333 小时**，来自 24 档中文播客。

**本仓库只有书目，没有音频。** 这里不包含任何音频文件、下载入口或分享地址；
所有节目版权归各制作方所有，想听请到各播客平台的官方渠道搜索节目名。

## English

A curated listening index of Chinese-language podcasts about **cities** — history, food and local chronicles, organised by place.

Currently **33 cities / regions, 241 episodes, ~333 hours**, drawn from 24 Chinese podcasts.

**Metadata only — no audio is hosted here.** This repository contains no audio files,
no download entries and no share links. All rights belong to the original producers;
please listen through the official channels of each podcast.

### Files

| File | Description |
| --- | --- |
| `index.html` | The listening index, grouped by city, with episode duration and show name |
| `poster.png` | Summary poster |

Sorted by total duration, descending. "多地" (multi-city) and "海外" (overseas) come last.

### Notes

- Selection criteria: episodes at least 40 minutes long, centred on one place, told by
  locals or long-term residents.
- A personal listening list, shared for reference only. No audio content included.
